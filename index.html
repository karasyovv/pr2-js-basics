Завдання 2: Форматування номерів телефону

Функція formattedPhone(phone) перетворює рядок до формату +38 (0XX) XXX-XX-XX та перевіряє коректність. 

formattedPhone('+80664567890') // +8 (066) 456-78-90
formattedPhone('+380664567890') // +38 (066) 456-78-90
formattedPhone('80971234567')   // +38 (097) 123-45-67
formattedPhone('0671234567')    // +38 (067) 123-45-67
formattedPhone('12345')         // Невірний формат...
